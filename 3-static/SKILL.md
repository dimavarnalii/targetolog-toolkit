# Статика без «ШІ-вигляду» (3-static)

Скриптів у модулі немає: ти готуєш тексти промптів, користувач вставляє їх у ChatGPT (потрібен акаунт з генерацією зображень) і показує результати. Нічого не вигадуй: усі тексти на картинці бере з відповідей користувача.

## Чому видно «ШІ»

Прохання «зроби унікальний дизайн» модель трактує шаблонно: стокове фото на весь кадр, величезний жирний текст, мазок маркера, кнопка-таблетка, логотип. Лікування: не просити «унікально», а описати конкретну сцену зі світу клієнта (екран, записка, наліпка) і дати точний список рядків тексту.

## Крок 1. Питання користувачу (по одному блоку)

1. Проєкт і ніша, оффер (що саме отримує людина), для кого.
2. Мова тексту. Рядки для креативу: лише справжні. Відгуки і цифри лише реальні або явно позначені як демо.
3. Ніша з обмеженнями Meta (здоров'я, фітнес, фінанси)? Тоді без «до/після» тіла чи зубів.

## Крок 2. Дай користувачу Блок A (вставити один раз на чат)

```
Ти арт-директор, який робить статичні креативи для Meta Ads у форматі 4:5 (1080×1350). Далі я надсилатиму окремі завдання. Роби кожен за цими правилами.

ГОЛОВНЕ: креатив має виглядати як реальний предмет або екран зі світу клієнта (скриншот, записка, документ, пост, наліпка на предметі), а не як рекламний банер. Ніякої стокової фотографії з накладеним текстом.

ТЕКСТ:
- На зображенні лише ті рядки, які я дам у полі «Текст». Нічого не додавай і не повторюй.
- Без логотипа, без кнопки, без стрілок. Кнопку дії Meta додає сама.
- Усі слова пиши кирилицею без помилок. Шрифт має відповідати сцені (рукописний, системний шрифт телефону, штамп, друкарська машинка).

КОМПОЗИЦІЯ:
- Дотримуйся сцени, яку я опишу. Не міняй її на «фото людини з великим текстом».
- Композиція асиметрична, головний елемент зміщений від центру, вільне місце лишається навмисно.
- Текст або всередині сцени (на папері, екрані, наліпці), або один великий елемент у вільній частині кадру.
- Не використовуй: мазки маркера за текстом, кнопки-таблетки, курсивний жирний шрифт, свічення, градієнти, ідеальних усміхнених моделей.

ЖИВІ ДЕТАЛІ: тіні, зморшки на папері, відбитки пальців на екрані, природне світло з одного боку, трохи неідеальний ракурс.

Відповідай одразу зображенням.
```

Якщо інструмент не підтримує «один раз на чат», вставляй Блок A перед кожним завданням.

## Крок 3. Сцени (у Блоці B вказуй номер)

1. **Чат у месенджері.** Скриншот екрана телефона в стилі iOS, діалог: клієнт питає, бізнес відповідає з оффером. Текст лише в повідомленнях.
2. **Великий факт.** Аркуш цупкого паперу з текстурою, вид зверху під кутом. Одне слово або число великим штампом чи друкарською машинкою, зміщене в нижній лівий кут; дрібний підпис під ним.
3. **Ручний документ.** Вид зверху: аркуш на столі, текст від руки, одна фраза обведена, поруч чашка й ручка.
4. **Предмет з наліпкою.** Макро-знімок товару на реальній поверхні, на ньому паперова наліпка з текстом. Без людини.
5. **Повідомлення-відгук.** Скриншот повідомлення клієнта на нейтральному фоні. Лише реальні відгуки.
6. **Схема від руки.** Три вузли зі стрілками маркером на білій дошці. Підписи у вузлах.
7. **Нотатки.** Скриншот застосунку нотаток (жовтий папір), текст як чернетка думки.

## Крок 4. Блок B (завдання на кожен креатив)

```
Проєкт: [назва]
Оффер: [оффер]
Для кого: [аудиторія]
Сцена: №[номер] [назва]
Текст (лише це, нічого більше):
[рядок 1]
[рядок 2]
```

Підготуй для користувача 3 завдання Блоку B (різні сцени) і лиши його вставляти по одному. Один креатив = одне повідомлення, правки в тому ж чаті.

## Крок 5. Оцінка кожного результату (користувач дивиться сам)

- Чи зрозуміло, що за продукт і для кого, з першого погляду.
- Кожне слово без помилок (кирилицю модель іноді псує). Якщо помилка лишається: попроси перегенерувати лише з виправленим словом, або прибери текст і накладі його в Canva/Figma.
- Читається на телефоні. Не схоже на інші креативи цього клієнта. Не вийшло «як банер»: поверни до сцени одним уточненням.
- Реальні відгуки й цифри: перед запуском звір з джерелом.

## Підводні камені (з тестів автора)

- Модель іноді показує екран на фізичному телефоні замість плоского скриншота. Якщо потрібен чистий скриншот, додай у сцену: «лише екран, кадр обрізаний по краях екрана, без корпусу телефона».
- Знак мінус інколи стає дефісом: на сприйняття не впливає.
- Заборону «текст зліва, зображення справа» не давай: модель віддзеркалює макет. Описуй сцену, а не заборони.
- Модуль не публікує і не запускає рекламу. Готові картинки користувач завантажує в Meta сам.
