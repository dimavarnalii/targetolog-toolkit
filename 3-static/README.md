# 3-static: статичні креативи через ChatGPT

Модуль без коду: бриф-шаблон, формули тексту, візуальні ідеї під ніші, стилі й команди правок для ChatGPT (або іншої моделі зображень). Повний процес для агента: `SKILL.md`.

Що потрібно: акаунт ChatGPT із генерацією зображень (на безкоштовному плані ліміти на кілька спроб за день, залежать від OpenAI), логотип клієнта, опис продукту з фактами.

Як користуватись: попросіть агента виконати модуль 3. Він запитає про бренд, продукт і дозволені факти, складе головний промпт, а ви вставите його в ChatGPT і доведете результат короткими правками.

Перевірка: метод автор застосував на сотнях креативів для онлайн-освіти; для цього набору перевірено шаблон на ніші, не пов'язаній з освітою для бухгалтерів (школа англійської): дизайн реклами, акцентний заголовок, предмет зі світу ніші, іконки, кнопка, кирилиця без помилок. Модуль нічого не запускає на комп'ютері й не звертається до мережі.
