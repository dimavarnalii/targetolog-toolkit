# 3-static: статичні креативи без «ШІ-вигляду»

Модуль без коду: правила, сцени і шаблони промптів для ChatGPT (або іншої моделі зображень). Повний процес для агента: `SKILL.md`.

Що потрібно: акаунт ChatGPT із генерацією зображень (безкоштовного плану достатньо для кількох спроб на день, ліміти залежать від OpenAI).

Як користуватись: попросіть агента виконати модуль 3. Він запитає про проєкт, оффер і тексти, підготує Блок A (правила) і кілька завдань Блоку B (сцена + точні рядки). Ви вставляєте їх у ChatGPT по одному, а результат оцінюєте за чеклістом в `SKILL.md`.

Перевірено автором на двох прикладах (чат-скриншот і наліпка на товарі, вигадані проєкти): текст без помилок, лише задані рядки, вигляд реального предмета. Сцени «великий факт», «ручний документ», «схема від руки», «нотатки» і «відгук» ще не проганялись. Модуль нічого не запускає на комп'ютері й не звертається до мережі.
