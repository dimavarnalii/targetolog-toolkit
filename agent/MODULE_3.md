# Модуль 3: Статика без «ШІ-вигляду»

> Для ШІ-агента. Спершу прочитай `SECURITY.md` і `agent/RULES.md`.

**Результат:** Промпти й завдання на 3 креативи 4:5 під ваш проєкт  
**Потрібно:** Акаунт ChatGPT із генерацією зображень; код і Python не потрібні  
**Статус:** Перевірено на двох сценах (чат-скриншот і наліпка на товарі, вигадані проєкти): текст без помилок, лише задані рядки, вигляд реального предмета. Інші сцени (великий факт, ручний документ, схема, нотатки, відгук) не проганялись. Результат залежить від моделі й лімітів вашого плану.

## GOAL
- Підготувати для користувача промпти й завдання на статичні креативи 4:5 для ChatGPT так, щоб результат виглядав як реальний предмет чи екран зі світу клієнта, а не як банер. Скриптів немає: картинки генерує користувач у своєму ChatGPT.

## READ_FIRST
- 3-static/SKILL.md (процес, Блок A, 7 сцен, шаблон Блоку B, оцінка, підводні камені), 3-static/README.md.

## ASK_USER (по одному)
- Проєкт і ніша, оффер (що саме отримує людина), аудиторія, мова тексту.
- Рядки тексту для картинок: лише від користувача. Відгуки лише справжні; цифри й терміни лише підтверджені.
- Ніша з обмеженнями Meta (здоров'я, фітнес, фінанси): без «до/після» тіла чи зубів.

## STEPS
- 1) Дай користувачу Блок A з SKILL.md цілком (один раз на чат; якщо чат не пам'ятає, перед кожним завданням).
- 2) Підготуй 3 завдання Блоку B з різними сценами (1-7), тексти лише користувача. Дай по одному, один креатив на повідомлення.
- 3) Результат оцінює користувач: слова без помилок, зрозумілий продукт, читається на телефоні, не схоже на банер. Далі правки в тому ж чаті.

## VERIFY
- Попроси користувача перевірити кожне слово на картинці. Помилка в кирилиці: перегенерація з виправленим словом або текст у Canva/Figma. Вигаданий відгук чи цифра на картинці: заміни або прибери.

## NEVER
- Не вигадуй відгуків, цифр, цін, гарантій і дефіциту. Не додавай логотип і кнопку на зображення. Не проси пароль чи токен ChatGPT. Не публікуй і не запускай рекламу.

## KNOWN_LIMITS
- Перевірено лише сцени 1 і 4. Модель іноді показує екран на фізичному телефоні: тоді додай «лише екран, без корпусу». Ліміти генерації залежать від плану ChatGPT.
