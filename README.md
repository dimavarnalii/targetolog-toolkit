# targetolog-toolkit

Скрипти й інструкції для набору «Toolkit для таргетолога».

Репозиторій призначений для ШІ-агента, який виконує інструкції з PDF-книги. Для людини тут немає чого читати: усе пояснено в книзі.

- `START_HERE.md` вхід для агента.
- `SECURITY.md` що роблять скрипти й куди звертаються.
- `CHECKSUMS.txt` контрольні суми файлів цього тега.
- `agent/` правила й інструкції модулів.
- `2-video/`, `4-audit/`, `5-landing/` скрипти модулів; `3-static/` лише промпти (без коду).

Беріть файли за тегом (наприклад, `v1.0`), а не з гілки `main`.
