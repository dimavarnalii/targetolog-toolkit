# Монтаж рекламних креативів (пакет скриптів)

Ти працюєш на комп'ютері користувача зі скриптами з папки пакета (`PKG`). Скрипти детерміновані: твоя робота — вибрати моменти й межі,
написати конфіги (`creatives.json`), хуки, ключові слова, запустити скрипти, перевірити результат і показати кадри. Не пиши ffmpeg-граф з нуля,
якщо його вже будує скрипт. Нічого не вигадуй: якщо скрипт чогось не вміє — скажи про це.

## Крок 0. Налаштування і перевірка середовища (завжди першим)

1. Запитай у користувача (або знайди), де лежить папка пакета → це `PKG` (в ній `scripts/`, `ad_creatives/`, `references/`, `library_example/`, `remotion_avatar/`).
2. Налаштування — змінні середовища (задай у цьому сеансі; запропонуй користувачу додати їх у систему). Усі необов'язкові, крім випадку, коли ffmpeg не в PATH:
   - `VM_ROOT` — робоча папка (за замовчуванням `~/ad-montage`): `sources/`, `projects/`, `done/`, `library/`. Диск із запасом місця.
   - `VM_FFMPEG`, `VM_FFPROBE` — шляхи, якщо ffmpeg не в PATH.
   - `VM_MUSIC` — його трек (mp3/wav); без нього музики немає.
   - `VM_WHOOSH` — його whoosh для перебивок; без нього звуків немає.
   - `VM_ASS_FONT` — назва шрифта субтитрів (за замовчуванням «Arial Black», має бути встановлений); `VM_FONTS_DIR` — папка з .ttf, якщо шрифт не встановлено.
   - `VM_FONT_FILE` — .ttf для підписів на контактних листах; `VM_WHISPER_MODELS` — кеш моделей; `VM_BRAND` — назва підпапки результату.
   - Для шортсів додатково `VM_BANNER`, `VM_OUTRO_CARD` (його картинки; без них плашки й кінцівки немає).
   У Windows перед запуском Python: `PYTHONIOENCODING=utf-8`.
3. Запусти `python PKG/scripts/vm_config.py`. Він показує шляхи й друкує «ПРОБЛЕМА: …», якщо немає ffmpeg/ffprobe або Python-пакета faster-whisper.
   Нічого не встановлюй без згоди: поясни користувачу, що ставити (ffmpeg із офіційного сайту; `pip install faster-whisper numpy`),
   і дочекайся, поки він встановить або скаже «став». Далі не йди, поки перевірка не пройде.
4. Створи `VM_ROOT/projects/<назва>/` для проєкту. **Усі скрипти `ad_creatives/*` запускай, перебуваючи в цій папці проєкту.**
5. Прочитай `PKG/references/ad_creatives.md` (креативи) і `PKG/references/editing_rules.md` (правила, що відрізняють якісний монтаж: темп, перебивки, субтитри, звук, контроль) перед роботою; при проблемах — `PKG/references/pitfalls.md`.

## Режими

- **Креативи з сирих телефонних дублів** (основний): процес нижче.
- **Готовий ролик з AI-аватаром / TTS** (різати не можна, оживити візуалом): `PKG/references/avatar_remotion.md` (Remotion, потрібен Node.js; необов'язковий блок).
- **Шортси з довгого відео**: `PKG/references/shorts.md` (`yt_fetch.py`, `shorts.py`); лише для матеріалу, на який у користувача є права.

## Процес: креативи (з папки проєкту)

1. **Проксі**: `python PKG/ad_creatives/make_proxies.py <папка_з_сирими> [--ext MOV,MP4]` → `proxy/*.mp4` (1080×1920, 30 fps CFR, SAR 1, GOP 15, faststart; дублі кадрів зі смартфона прибираються, вимкнути `--no-dedup`).
2. **Транскрипт**: `python PKG/ad_creatives/transcribe_medium.py --lang <мова> IMG_0001 IMG_0002 ...` → `IMG_0001.words_m.json` (у фоні; займає багато часу на слабкому ноуті; не запускай паралельно з рендером).
   Мову запитай у користувача (`uk`, `ru`, `en`…): автовизначення на суржику помиляється.
3. **Огляд дубля**: `python PKG/ad_creatives/tl_inspect.py IMG_0001` — транскрипт по фразах і `preview/t_IMG_0001.png`; покажи користувачу, які діапазони виключити (`exclude`),
   які слова виправити (`fixes`/`fix_at`). Для слів, де розпізнавання «проковтнуло» фразу: `python PKG/scripts/transcribe_words.py IMG_0001.wav IMG_0001.words.json --model small --lang <мова>`,
   потім `python PKG/ad_creatives/gapcheck.py IMG_0001`, фрази додай в `inject`. Знайти слово: `python PKG/ad_creatives/findw.py IMG_0001 слово`.
4. **Перебивки** (за наявності бібліотеки в `VM_ROOT/library`): `python PKG/ad_creatives/broll_sheet.py` → `preview/broll_sheet.png`, обери кліпи за змістом слів (не на абстрактні стоки заради кількості). Якщо бібліотеки немає — монтуй без перебивок і скажи про це.
5. **creatives.json** за схемою з `references/ad_creatives.md` та `ad_creatives/creatives.example.json`: `source`, `words`, `exclude`, `fixes`, `fix_at`, `inject`, `keywords`, `hook` (`\n` — рядок, `*акцент*`), `music_vol`, `speed` (`"auto"` за замовчуванням: повільну мову до ~3 слів/с, не швидше ×1,25; або число; `1` для аватара/TTS), `cutaways` (`at` у часі ДЖЕРЕЛА).
   Хук — лише те, що реально звучить у відео або підтверджено користувачем; не вигадуй цифр.
6. **Семпл спершу**: збери один креатив і подивись кадри (хук, середина, кінець); повний набір — лише після «ок» користувача.
   Команда: `python PKG/ad_creatives/build_creative.py creatives.json <name>` (або `all`). Правки лише тексту: додай `--subs-only` (швидко).
7. **Перевірка кожного файлу (обов'язково, `build_creative.py` сам не перевіряє)**:
   `python PKG/scripts/verify_video.py <файл_9x16> --fps 30` і `... <файл_4x5> --fps 30 --size 1080x1350`. Будь-який FAIL → файл не віддавай, дивись `pitfalls.md`.
   Дістань кадри з початку/середини/кінця (`ffmpeg -ss T -i файл -frames:v 1 ...`) і подивись: хук читається, субтитри не на обличчі.
   Контактний лист: `ffmpeg -i файл.mp4 -vf "fps=1/2,scale=180:-1,tile=8x3" sheet.jpg` (шукай «спалахи» спікера, текст на обличчі, обрізані слова). Дублі тексту: `python PKG/scripts/repeats.py <файл>` (код 1 = є повтор; потребує faster-whisper).
8. **Віддача**: файли в `VM_ROOT/done/<дата>/<VM_BRAND>/<name>_9x16.mp4` та `_4x5.mp4`. Покажи таблицю: № / джерело / тривалість / хук.

## Правила, що коштували переробок

1. Чорний екран, звук є — три причини: moov в кінці файлу, змішаний fps у перебивках, SAR не 1:1. Скрипти це лікують (`+faststart`, CFR, `setsar=1`); `verify_video.py` ловить. Не рендери руками без цих прапорців.
2. Музика ледь чутна, голос головний. Без клік/поп-звуків.
3. Хук/тема висять 4.5 с; текстові плашки й картки не менше 3 с.
4. AI-аватар / TTS: паузи не різати, ролик не коротшати; TTS (~230 слів/хв) сповільнювати до 0.9×.
5. Запас на кінці слів від 0.25 с (тісні межі слів зрізають закінчення). УВАГА: `build_creative.py` лишає 0.10 с після слова (PAD_OUT) і 0.06 с перед (PAD_IN); якщо на слух закінчення слів зрізані, повідом користувача й піднімай PAD_OUT разом із GAP_MAX у скрипті (лише за згодою).
6. Спершу семпл (для аватара 0–10 с), повний рендер — після схвалення.
7. Мова субтитрів і хуків = мова відео.

## Реалістичні очікування

Автор на слабкому ноуті без GPU (i5 10-го покоління) мав ~10–15 хв на креатив. Не запускай транскрипцію й рендер паралельно. Довгі кроки — у фоні з повідомленням про статус.

## Чого не робити

- Не змінюй і не копіюй у пакет музику/ефекти/кліпи/шрифти без прав користувача; не вигадуй можливостей, яких немає в скриптах.
- Не вводь і не проси токени/паролі; не читай `.env`.
- Не ставь і не качай нічого без згоди користувача.
- Скрипти пакета не редагуй без запиту; конфіги проєкту — у папці проєкту.
