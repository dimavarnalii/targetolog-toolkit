# Рекламні креативи із сирих дублів (9:16 + 4:5)

Скрипти лежать у `ad_creatives/`. Їх запускають **з папки проєкту** `<VM_ROOT>/projects/<назва>/` (поточна папка = папка проєкту):
там з'являться `proxy/`, `*.wav`, `*.words_m.json`, `creatives.json`, `work/`, `preview/`.
Нічого копіювати з пакета не треба.

Перед усім: `python scripts/vm_config.py` — покаже шляхи, наявність ffmpeg/faster-whisper і що не задано.

## Що робить `build_creative.py`

```
cd <VM_ROOT>/projects/<назва>
python <пакет>/ad_creatives/build_creative.py creatives.json <name|all> [--subs-only]
```

1. За `words_m.json` будує сегменти: вирізає паузи > 0.30 с (GAP_MAX; залишає 0.06 с повітря перед словом і 0.10 с після) і діапазони `exclude` (невдалі дублі).
2. Склеює шматки проксі; на кожному другому шоті punch-in зум ×1.12 (ховає джамп-кати; зміна не раніше ніж через ~2.2 с);
   перебивки на весь кадр з Ken Burns (зум до ×1.10); whoosh на вході перебивки (якщо задано `VM_WHOOSH`);
   музика під голосом (sidechaincompress; `music_vol`, у коді дефолт 0.16, у прикладах автора 0.10; тільки якщо є `VM_MUSIC` або `"music"` у конфігу);
   loudnorm I=-15 → `work/<name>_comp.mp4` без тексту.
3. Субтитри (2–3 слова, підсвітка ключових, pop) + плашка-хук (`hook`; `*текст*` = жовтий акцент; `hook_dur` за замовчуванням 4.5 с) →
   два рендери: `done/<дата>/<VM_BRAND>/<name>_9x16.mp4` і `_4x5.mp4` (центр-кроп 1080×1350).
`--subs-only` — перерендер лише тексту поверх готового `_comp.mp4` (швидко, для правок субтитрів/хука).

Скрипт **сам не перевіряє** готові файли: після рендеру запустіть
`python <пакет>/scripts/verify_video.py <файл> --fps 30 [--size 1080x1350 для 4x5]`.

## Підготовка (по порядку)

1. **Проксі**: `python <пакет>/ad_creatives/make_proxies.py <папка_з_сирими> [--ext MOV,MP4]` → `proxy/<ім'я>.mp4`
   (1080×1920, 30 fps CFR, SAR 1, yuv420p, GOP 15, `+faststart`; автоповорот; горизонтальне джерело ОБРІЗАЄТЬСЯ по центру, не обгортається полями).
2. **Транскрипт medium**: `python <пакет>/ad_creatives/transcribe_medium.py --lang uk IMG_0001 IMG_0002` →
   `IMG_0001.words_m.json` (wav 16 кГц mono створюється з `proxy/IMG_0001.mp4`; без VAD).
3. **Страховка від «проковтнутих» фраз** (за потреби): `python <пакет>/scripts/transcribe_words.py IMG_0001.wav IMG_0001.words.json --model small --lang uk`,
   далі `python <пакет>/ad_creatives/gapcheck.py IMG_0001` — для кожної паузи > 0.7 с у medium показує, що почула small.
   Якщо там є фраза — додайте її в `inject` (інакше скрипт виріже її як паузу).
4. **Огляд дубля**: `python <пакет>/ad_creatives/tl_inspect.py IMG_0001 [крок_с]` — транскрипт по фразах + `preview/t_IMG_0001.png`
   (таймлайн кадрів); `python <пакет>/ad_creatives/findw.py IMG_0001 слово ...` — де звучить слово.
5. **Перебивки**: `python <пакет>/ad_creatives/broll_sheet.py [папка_бібліотеки]` — контактний лист з підписами (див. `library_example/README.md`).

## creatives.json

Файл `{"creatives": [ {...}, {...} ]}`; приклад — `ad_creatives/creatives.example.json`. Поля креативу:

| Поле | Значення |
|---|---|
| `name` | ім'я для файлів результату |
| `source` | проксі відносно папки проєкту, напр. `proxy/IMG_0001.mp4` |
| `words` | `IMG_0001.words_m.json` |
| `exclude` | `[[від, до], ...]` секунди джерела: невдалі дублі (слова в цих діапазонах скидаються) |
| `fixes` | `{"розпізнано": "правильно"}` — заміна слова скрізь (ключ без розділових знаків, нижній регістр) |
| `fix_at` | `[[t, "слово"], ...]` — заміна одного слова, що починається біля часу t (±0.15 с) |
| `inject` | `[[t0, t1, "фраза"], ...]` — додати фразу, яку медіум пропустила (слова рівномірно в проміжку) |
| `keywords` | основи слів для жовтої підсвітки (нижній регістр) |
| `hook` | текст плашки; `\n` — новий рядок, `*текст*` — акцент |
| `hook_dur` | секунд (за замовчуванням 4.5) |
| `music`, `music_vol` | свій трек (інакше `VM_MUSIC`) і гучність під голосом |
| `cutaways` | `[{"at": t, "dur": 1.6, "file": ..., "ss": 2.0}]` — `at` у часі **джерела** (скрипт сам перерахує після вирізання пауз); `file`: абсолютний шлях, `lib/<категорія>/<клип>` (бібліотека) або `px/<ім'я>` (інше проксі проєкту); `ss` — з якої секунди кліпу брати |

Скрипт зупиниться з помилкою, якщо перебивка коротша за `ss + dur`.

## Нюанси

- Слабкий ноут без GPU (автор: i5 10-го покоління): ~10–15 хв на креатив; транскрипцію і рендер паралельно не запускати.
- Жирний шрифт 90 px вміщує ~13 символів у ряд на 1080 px — довгі групи слів скрипт зменшує сам, але хук перевіряйте очима.
- Шрифт субтитрів задається `VM_ASS_FONT` (за замовчуванням "Arial Black", має бути встановлений; інакше `VM_FONTS_DIR`).
- Не називайте допоміжні скрипти іменами модулів stdlib (`inspect.py` зламав numpy).
- Якщо ffmpeg не знаходить `-/filter_complex`: див. `references/pitfalls.md`.
