# Шортси з довгого відео (необов'язковий режим)

Основна тема модуля — рекламні креативи (`ad_creatives.md`). Цей режим — нарізка довгого відео (ефір, вебінар, ваше YouTube-відео)
на вертикальні кліпи 30–50 с. Працюйте лише з матеріалом, права на який у вас є.

Команди (`<пакет>` = папка з пакетом; усі шляхи беруться з `scripts/vm_config.py`):

```
python <пакет>/scripts/vm_config.py                                   # перевірка середовища
python <пакет>/scripts/yt_fetch.py "<посилання або файл>" MY_PROJECT --lang uk
python <пакет>/scripts/scan_sheet.py <відео> out.jpg 60 300 600       # кадри з сіткою для кропів
python <пакет>/scripts/shorts.py <VM_ROOT>/projects/MY_PROJECT/clips.json --stage base      # лише основи + bases_sheet.jpg
python <пакет>/scripts/shorts.py <VM_ROOT>/projects/MY_PROJECT/clips.json --stage render    # рендер у done/<дата>/ + preview_sheet.jpg
python <пакет>/scripts/shorts.py clips.json 2 5 --stage render         # лише кліпи 2 і 5
```

## 1. Як вибирати моменти

Кліп дивляться без контексту ролика, тому він має працювати сам:
- **Одна думка з розв'язкою**: проблема → пояснення → висновок/порада.
- **Перші 2–3 с чіпляють**: питання, різке твердження, цифра, помилка, конфлікт. Якщо сильна фраза в середині — почніть ближче до неї.
- **30–50 с**. Коротше 25 — мало суті; довше 55 — падає досмотр (орієнтири автора).
- **Межі по словах**: старт — початок речення, кінець — завершена думка. Сегменти whisper часто починаються посеред речення — дивіться `words.json`; беріть початок першого слова / кінець останнього + ~0.2 с.
- **Склейка двох шматків** (`segments` з 2 діапазонами), коли розв'язка історії приходить пізніше.
- **Не беремо**: рекламу в середині, «секунду, мене відволікли», технічні паузи, повтори.
- Кліпи не повинні дублювати один одного за змістом.

## 2. Кропи

`scan_sheet.py <відео> <out.jpg> <t1> <t2> ... [--cols 3] [--grid 100]` — кадри з червоною сіткою кожні 100 px **джерела** і підписом часу. Рахуйте координати по лініях сітки.

Розміри панелей результату:
- `split`: верх 1080×960 і низ 1080×960 → співвідношення **1.125**. Прямокутник іншого співвідношення не спотвориться (scale-to-cover + центр-кроп), але обріже краї — тому підбирайте близько до 1.125 (напр. 640×569, 1160×1031, 1080×960).
- `crop`: 1080×1920 → співвідношення **0.5625** (напр. 607×1080 з 1920×1080).
- `fit`: без координат — весь кадр по ширині на розмитому фоні (для скрінкастів без обличчя).

Типова компоновка «вебкамера + екран»: верхня панель — прямокутник з обличчям (коло вебкамери), нижня — екран/графік, починаючи правіше від краю вебкамери,
щоб у нижній половині не було шматка обличчя. Координати для кожного джерела визначайте заново по `scan_sheet`; вебкамера може зміщуватись між кліпами — перевіряйте кожен.

## 3. clips.json

```json
{
  "project": "MY_PROJECT",
  "defaults": {
    "layout": {"type": "split", "top": [0, 705, 640, 569], "bottom": [570, 230, 1160, 1031]},
    "caption_model": "medium",
    "lang": "uk",
    "prompt": "терміни, імена, які whisper має писати правильно",
    "render": {}
  },
  "clips": [
    {
      "id": "1",
      "slug": "short_slug",
      "segments": [[93.1, 119.3], [242.2, 261.0]],
      "hook": "ПЕРШИЙ РЯДОК\nДРУГИЙ РЯДОК",
      "topic": "ТЕМА: СУТЬ",
      "keywords": ["слово1", "слово2"],
      "description": "1–2 речення суті...\n\n👉 заклик до дії\n\n#хештег1 #хештег2",
      "layout": {"type": "split", "top": [90, 705, 640, 569], "bottom": [660, 230, 1080, 960]}
    }
  ]
}
```

Поля кліпу: `id` (рядок), `slug` (суть для назви файлу), `segments` (секунди джерела), `hook`, `topic`, `keywords`, `description`, необов'язково `layout`,
`caption_pos` ([x, y]; дефолт — 960 для split, 1180 інакше), `caption_model` / `lang` / `prompt` (перекривають defaults), `render` (оформлення лише цього кліпу).

`source_video` береться з `meta.json` (його пише `yt_fetch.py`); можна задати явно в корені clips.json.
`caption_model`: `medium` (дефолт; перерозпізнає аудіо самого кліпу — точніше) або `reuse` (нарізати з повного `words.json` — швидше, але з помилками small).

Тексти: `hook` — 2 рядки КАПСОМ, до ~22 символів у рядку, мова = мова відео, лише те, що реально звучить у кліпі; `topic` — плашка зверху «ТЕМА: СУТЬ».
`keywords` — основи слів для жовтої підсвітки (нижній регістр).

## 4. Ключі оформлення (`defaults.render` / `clip.render`)

Дефолти в `shorts.py` (`RENDER_DEFAULTS`):
- `intro_duration` 4.5 — скільки висять тема і хук.
- `image_banner` — анімована плашка-картинка унизу (виїжджає на 1.5 с і плавно гойдається). **Увімкнено лише якщо задано `VM_BANNER`** (ваш файл). Вимкнути: `"image_banner": null`.
- `music` — **лише якщо задано `VM_MUSIC`**; volume 0.015, fade 1.5.
- `outro` — 3 с картка-кінцівка на розмитому останньому кадрі. **Лише якщо задано `VM_OUTRO_CARD`**. Вимкнути: `"outro": null`.
- `progress_bar_color`, `banner_text` (текстова плашка замість картинки), `whoosh` (`{"file": "<ваш whoosh>", "volume": 0.35}` — звук на перебивках), `cutaways`.

Субтитри: 2 слова, біла заливка + чорний контур, ключові слова жовті, легкий зум-удар на початку кожного речення (`build_dynamic_ass.py` + `build_overlay_filter.py`); шрифт — `VM_ASS_FONT`.

## 5. Перебивки

`cutaways: [{"start": 12.3, "end": 14.0, "format": "full|split|circle", "file": "<шлях>"}]` — час у секундах **кліпа** (після склейки).
`full` — на весь кадр, `split` — спікер зверху / перебивка знизу, `circle` — перебивка на фоні + спікер у колі. Звук завжди з основного відео.
Бібліотека — ваша власна (див. `library_example/README.md`). Для спліт-формату з графіком перебивки зазвичай не потрібні.
