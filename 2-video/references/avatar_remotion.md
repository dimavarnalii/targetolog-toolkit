# Відео-аватар / готовий дикторський ролик → креатив у стилі «кораловий» (Remotion) — НЕОБОВ'ЯЗКОВИЙ блок

Коли брати: на вході **одне готове відео** (AI-аватар, TTS, вже зведений голос), його не треба різати, треба «оживити» візуалом.
Для сирих телефонних дублів — `ad_creatives.md`.

Потрібно додатково: Node.js + npm, інтернет при першому запуску (npm-пакети; шрифти Unbounded і Montserrat Remotion тягне з Google Fonts).
Ліцензія Remotion: безкоштовна не для всіх (умови для компаній) — перевірте на remotion.dev/license до комерційного використання.

## Шаблон (папка `remotion_avatar/`)

- `src/avatar/AvatarCreative.tsx` — **шаблон**: весь стиль у коді, усе, що залежить від відео, — у конфігу.
- `public/<dir>/creative.json` — конфіг ролика (приклад — `public/example/creative.example.json`).
- Композиції `AvatarCreative` (9:16) і `AvatarCreative45` (4:5). Тривалість рахується сама (`sourceDur / speed`);
  інший ролик: `--props='{"config":"<dir>/creative.json"}'`.
- `Captions7.tsx` (субтитри), `AvatarCards.tsx` (картки counter / two / cross).
- Встановлення: `cd remotion_avatar && npm i`; перегляд: `npx remotion studio`.
- Автор перевірив шаблон на своєму середовищі; у цьому пакеті його **не запускали після очищення від прив'язок** — [перевірити автору].

Стиль не міняйте в коді без потреби: правки під ролик — у `creative.json`.

## Стиль (зашитий у шаблон; затверджений автором)

| Елемент | Як |
|---|---|
| Акцент | кораловий `#FF6F91` (`accent` у конфігу). Чорний текст на акценті |
| Темп | `speed` 0.9: аватар `playbackRate`, голос `atempo 0.9`. TTS ~230 слів/хв без цього «дуже швидко». Анімації не сповільнюються (усі часи ÷ speed). Ролик стає довшим — це ок, коротшим — ніколи |
| Паузи | не різати взагалі |
| Хук | 0–4.5 с, 2–3 плашки зверху y=150 (Unbounded 900, 76 px): перша темна, решта коралові; вилітають зі сторін по черзі, нахил ±2° |
| Плашки-тези | той самий вигляд, 2–3 штуки на ролик, ≥3 с, лише фрази, які реально звучать |
| Субтитри | Montserrat 900, 72 px, КАПС, білий з чорним контуром, y=1340; поточне слово на кораловій плашці з нахилом −2°; сторінки ~700 мс, розрив на розділових знаках і паузах >0.4 с; ховаються під картками й CTA |
| Стікери | вирізки (PNG з прозорістю) збоку, ширина 330–540 px, y≈760–820, білий контур, похитування |
| Кількість перебивок | автор вимагав **мінімум 25 на ролик (кліпи + стікери)**; кожна під слово, що звучить, і довірчого вигляду (власні кадри спікера, предмети з тексту, реальні дії); без абстрактних стоків заради кількості — краще плашка з фразою |
| Кліп-картки | кліп 420×540, біла рамка, нахил 5°, виїжджає збоку; сторони чергувати зі стікерами; обличчя не закривати (зона y≈380–900) |
| Картки | `counter` (лічильник-штамп), `two` (заголовок + 2 кружки + підпис), `cross` (список із закресленням); y≈880–1400, 3–4.4 с |
| Зуми | наїзд 1.0→1.07 під хук; punch ×1.14 на 6–8 ключових словах (тримати 1 с) |
| Картинка | `contrast(1.07) saturate(1.18) brightness(1.03)` + віньєтка; смуга прогресу зверху 12 px |
| CTA | останні ~1.8 с, y=1280: пігулка-кнопка (текст CTA з мовлення, 2 рядки) з пульсом, стрілка ▼ |
| Звук | голос через `avatar_audio.py` → -14 LUFS; музика `musicVol` 0.05 (0.09 після нормалізації здалась гучною); pop/whoosh 0.3–0.35 |
| Формат | 9:16; 4:5 — на запит |

## creative.json — що заповнити (усі часи — секунди **джерела**, за `words.json`)

| Поле | Що |
|---|---|
| `dir`, `sourceDur` | папка в `public/`, тривалість джерела |
| `hook` | `dur` 4.5, `lines` [{t, hl}] — 2–3 рядки ≤12 символів, `hl: true` = кораловий |
| `plates` | тези: `at`, `dur` ≥3, `lines` |
| `pinned` | плашка на весь ролик: `lines`, `top`, `size`, `hide` [[a,b]]. Автор від такої плашки відмовився (хук лише ~3–4.5 с на старті, зверху) — не використовувати без потреби |
| `punches` | 6–8 часів ключових слів, не ближче 2 с один до одного |
| `stickers` | `src`, `at` = слово − 0.2 с, `dur` 1.9–2.2, `side`, `w`, `y`, `rot` (±8–12) |
| `clips` | `src`, `at`, `dur` 1.6–2.7, `ss`, `side` |
| `cards` | `{type:"counter", at, dur:3, value, unit, from}`, `{type:"two", at, dur:3.84, title, sub}`, `{type:"cross", at, dur:4.4, title, items:[{text, at від початку картки}]}` |
| `cta` | `at` = початок фрази CTA, `lines` — 2 рядки КАПСОМ |
| `captionHide` | [[a,b]] — під лічильником, під `two`/`cross`, від CTA до кінця |
| необов'язкові | `speed` (0.9), `accent`, `musicVol` (0.05), `voice` (voice_090.wav), `music` (music.mp3) |

Вміст `public/<dir>/` робите ви: `src.mp4`, `voice_090.wav`, `music.mp3`, `pop.mp3`, `whoosh.mp3` (свої, з правами), `captions.json`, стікери `.png`, кліпи `.mp4`, `creative.json`.
Файли аудіо (`music/pop/whoosh`) шаблон вимагає завжди — без них рендер впаде.

## Процес

1. **Транскрипт** (`scripts/transcribe_words.py` або `ad_creatives/transcribe_medium.py`) → `words.json`. Прочитати повністю, виправити помилки. Слів/хв > 200 → `speed` 0.9.
2. **Звук і субтитри** (з кореня пакета):
   ```
   python scripts/avatar_audio.py <джерело.mp4> remotion_avatar/public/<dir>/voice_090.wav --speed 0.9
   python scripts/words_to_captions.py <words.json> remotion_avatar/public/<dir>/captions.json --fix "погане=добре"
   ```
   Субтитри — у часі джерела, шаблон сам ділить на speed. Інший `speed` — той самий `--speed`.
   **Перевірка дублів у звуці** (Whisper може «ковтати» повтор фрази): окремого скрипта в пакеті немає — прослухайте ролик і порівняйте з `captions.json`.
   Музика з першого кадру: якщо у треку fade-in інтро — обрізати (`ffmpeg -ss 2 -i music.mp3 -af afade=in:d=0.05 music_cut.mp3`) і вказати `music` у конфігу.
3. **Стікери**: свої PNG із прозорим фоном (вирізки предметів зі згаданого в тексті). Автор отримував вирізки через зовнішній конектор (OpusClip `find_broll` + cutout); це залежить від акаунта й тут не відтворюється.
4. **Перебивки-кліпи**: `ffmpeg -i in.mp4 -t 8 -an -vf scale=-2:720,fps=25 broll1.mp4` у `public/<dir>/`.
5. **Конфіг**: скопіювати `creative.example.json` → `creative.json`, заповнити.
6. **Стопкадри** для перевірки: `npx remotion still src/index.ts AvatarCreative out/x.png --frame=N --scale=0.3 --props='{"config":"<dir>/creative.json"}'` на хуку, кожній картці/стікері, CTA, останньому кадрі.
7. **Семпл 0–10 с** (`--frames=0-249` при 25 fps) → показати; повний рендер лише після «ок».
8. **Рендер** (у фоні; автор: ~9 хв на 50 с відео): `npx remotion render src/index.ts AvatarCreative out/<name>.mp4 --crf=18 --props=...`, потім перекодувати для сумісності:
   `ffmpeg -i out/<name>.mp4 -vf "scale=out_range=tv:out_color_matrix=bt709,format=yuv420p,setsar=1" -color_range tv -colorspace bt709 -c:v libx264 -crf 18 -r 25 -c:a aac -b:a 192k -movflags +faststart final.mp4`
   і `python scripts/verify_video.py final.mp4 --fps 25 --size 1080x1920`. Remotion віддає full-range `yuvj420p`; одного `-pix_fmt yuv420p` мало — verify ловить FAIL.

## Граблі, які вже траплялись
- Сторінка субтитрів «перетікала» через приховані слова → розрив сторінки перед паузою >0.4 с (вже в коді).
- Остання фраза налазила на CTA → сторінка обрізається на початку наступного `captionHide` (вже в коді); діапазон CTA у `captionHide` обов'язковий.
- Подвійні пробіли між словами: токени вже мають пробіл спереду — padding 10 px, margin −6 px (вже в коді).
- «Музика стала голосніше» після нормалізації голосу (+13 дБ) → `musicVol` 0.05.
- ffprobe з двома файлами в одній команді падає — по одному.
- Перебивка, яку можна прочитати інакше, шкодить (приклад: торт під «отримає подарунки» читається як «торт — це подарунок»): підбирайте за змістом фрази.
