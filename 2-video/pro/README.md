# Pro-монтаж (рушій): сире відео → готові креативи 9:16 і 4:5

Вища якість, ніж у простого пакета (`../ad_creatives`): розшифровка по словах, вирізання дублів і обмовок, темп мови,
перебивки за змістом, кадрування за обличчям із плавними зумами, субтитри-плашки, контроль стиків, звук, перевірка
якості готового файлу. Рушій працює на вашому комп'ютері; «мозок» (монтажний лист) складає ваш ШІ-агент.

## Що потрібно (один раз)

| Що | Навіщо | Примітка |
|---|---|---|
| Python 3.11+ | рушій | `python -m venv .venv` і `pip install -r requirements.txt` |
| ffmpeg 7.0+ з libass | склейка, субтитри | Windows/Linux: звичайна збірка 7.0 або новіша (`-/filter_complex`); macOS: `brew install ffmpeg-full` |
| Node.js 18+ | рендер Remotion | `cd remotion && npm install` |
| Моделі | Whisper large-v3-turbo (~1,6 ГБ), YuNet (обличчя, ~0,2 МБ) | завантажуються лише за вашою згодою |

**Ліцензії.** Remotion безкоштовний для компаній до 3 працівників і для оцінювання, інакше потрібна Company License
(remotion.pro). Шрифт Montserrat: SIL OFL. Whisper: MIT. Вирівнювання MMS (необов'язкове): ваги мають некомерційну
ліцензію CC-BY-NC, тому за замовчуванням вимкнене. Музику й звуки пакет не містить: свої кладіть у `<дані>/input/audio/music`
(+ `tracks.json`) і `<дані>/sfx`; без них звуки синтезуються простими.

## Змінні середовища

| Змінна | Що робить |
|---|---|
| `VM_ROOT` | корінь даних і бібліотеки перебивок (`<VM_ROOT>/library`); за замовчуванням `~/ad-montage` |
| `MONTAGE_DATA` | папка `work/`, `output/`, `models/` (за замовчуванням `<VM_ROOT>/engine`); `MONTAGE_MODELS` окремо для моделей |
| `MONTAGE_LANG` | мова відео; `run.py` виставляє з `--lang` |
| `MONTAGE_BRAIN` | `agent` (за замовчуванням) або `cli` (виклик `claude -p`) |
| `MONTAGE_ALIGN` | `1` вмикає точні межі слів (torch, ваги CC-BY-NC) |
| `MONTAGE_WHISPER` | назва моделі Whisper (за замовчуванням `large-v3-turbo`) |
| `MONTAGE_ALLOW_DOWNLOAD` | `1` дозволяє Whisper завантажитись самому при розшифровці (за замовчуванням `run.py` вимагає `fetch_models.py --yes`) |
| `VM_FFMPEG`, `VM_FFPROBE` | шляхи до ffmpeg/ffprobe, якщо їх немає в PATH |

Музика: `<дані>/input/audio/music/tracks.json` у форматі `{"track.mp3": {"mood": "нейтральна, ритмічна", "duration": 120.0}}`; монтажний лист
може назвати лише ці файли (невідома назва ігнорується з попередженням). Поля каталогу перебивок `era` (before|after), `lowres`, `pip` задаються
`library_catalog.py describe ... --era before|after --lowres`.

## Де лежать дані

Код рушія можна тримати де завгодно. Дані (за замовчуванням `<VM_ROOT>/engine`, `VM_ROOT` за замовчуванням `~/ad-montage`;
змінити: `MONTAGE_DATA`): `work/` (кеш кроків), `output/` (готові ролики), `models/` (моделі; `MONTAGE_MODELS`).
Бібліотека перебивок: `<VM_ROOT>/library` з `catalog.json` (див. `../ad_creatives/library_catalog.py`, описи кадрів).

## Запуск

```
python run.py <відео> --lang uk --style box --formats 9x16,4x5 [--script сценарій.txt] [--density low|normal|high]
              [--music none|назва] [--name <назва_креативу>] [--target 45] [--brief "вказівки"] [--preview cut|fast]
```

Перший запуск зупиняється на кроці «Монтажний лист» (код 2): рушій зберігає завдання `work/<ім'я>.plan_request.md`.
**Агент** читає його, складає JSON за `SCHEMA` у `plan.py` і зберігає в `work/<ім'я>.edl.json`, потім запускає ту саму
команду ще раз. Кожен крок кешується, повтор продовжує з місця зупинки; `--replan` перескладає монтажний лист.

| Крок | Скрипт |
|---|---|
| Розшифровка по словах (дослівно: з «і…», «ну», фальстартами) | `transcribe.py` |
| (необов'язково) точні межі слів, `MONTAGE_ALIGN=1` | `align.py` |
| Паузи й нумерація слів | `prepare.py` |
| Монтажний лист (агент) | `plan.py` + `prompts/edit.md` |
| Склейка, темп мови по фразах, автовиправлення вигуків | `cut.py`, `verify.py`, `autofix.py`, `sync.py` |
| Кадрування за обличчям, контроль стиків | `track.py`, `reframe.py`, `joins.py` |
| Візуальний шар і рендер | `to_remotion.py` → `remotion/` (запасний FFmpeg-рендер: `--renderer ffmpeg`) |
| Контроль якості (гучність, пік, бітрейт, Rec.709, чорні/застиглі кадри) | `qa.py` |

Стилі субтитрів: `box` (плашка; колір `--box-color`), `pyshka` (дрібний білий капс на рівні грудей). Платформа:
`--platform yt` не змішує кадри «до» і «після» (поле `era` у каталозі) і не бере кадри з `sensitive_reason: тіло`.

## Межі

Не робить: аватар-ролики з HeyGen, окремі хук-ролики, картки Instagram, кольорокор під референс, розбір референсу.
Працює на CPU: ролик на 1 хв рахується 10–30 хв залежно від ноутбука; запускай у фоні.
