# Pro-монтаж: інструкція для агента

Спершу прочитай `../../SECURITY.md` і `../../agent/RULES.md`. Правила якісного монтажу: `../references/editing_rules.md`.
Користувач не програміст: говори просто, кажи, що відбувається і скільки чекати; довгі кроки запускай у фоні.

## 0. Перевірка середовища (один раз; кожна установка лише за згодою користувача)

1. Python 3.11+, venv у папці рушія: `python -m venv .venv`, потім `pip install -r requirements.txt`.
2. ffmpeg з libass у PATH (`ffmpeg -filters` містить `subtitles`). На macOS: `brew install ffmpeg-full`.
3. Node.js 18+, потім `cd remotion && npm install` (довго). Нагадай про ліцензію Remotion (README, «Ліцензії»).
4. Моделі: `python fetch_models.py yunet --yes` і `python fetch_models.py whisper --yes` (~1,6 ГБ): спершу спитай згоди.
5. Змінні середовища: `VM_ROOT` (де бібліотека перебивок і дані; за замовчуванням `~/ad-montage`), за потреби `MONTAGE_DATA`. Усі файли `work/` і `output/` нижче лежать у `<MONTAGE_DATA>` (за замовчуванням `<VM_ROOT>/engine`), а не в папці рушія. На Windows виставляй `PYTHONUTF8=1`. Ключів і токенів ці кроки не потребують.

## 1. Підготовка

- Бібліотека перебивок: `../ad_creatives/library_catalog.py scan` і описи кадрів (див. `../SKILL.md`, крок 4). Без бібліотеки монтуй без перебивок.
- Сценарій (якщо є) збережи в текстовий файл і передавай `--script`: хуки, терміни й еталон тексту беруться з нього.
- Питай по одному: мову відео (`uk`, `ru`, `en`), назву креативу від замовника (`--name`), цільову тривалість, щільність перебивок (`low|normal|high`), платформу (`meta|yt`).

## 2. Запуск і «мозок»

`python run.py <відео> --lang uk --style box --formats 9x16,4x5 [прапорці]` (у фоні). Він зупиниться з кодом 2 на кроці «Монтажний лист».

Тоді ТИ складаєш монтажний лист:
1. Прочитай `work/<ім'я>.plan_request.md` ПОВНІСТЮ: правила (`prompts/edit.md`), каталог перебивок, завдання, розшифровка з індексами слів.
2. Збережи JSON за `SCHEMA` в `plan.py` у `work/<ім'я>.edl.json`: `keep` (діапазони слів), `broll` (`at_word`, `to_word`, `clip`, `dur`, `clip_start`),
   `emphasis`, `word_fixes`, `overlays` (лише `cta_arrows`), `notes`. Кліпи бери лише з каталогу; немає доречного кадру: порожній `broll`.
3. Запусти ту саму команду ще раз. Попередження `увага:` у виводі поясни користувачу. Рендер Remotion іноді падає й сам повторює крок: це нормально.

## 3. Перевірка перед віддачею (обов'язково)

- Вивід кроку `Контроль якості` (`qa.py`) без ✗: гучність, пік, бітрейт, Rec.709, чорні/застиглі кадри, дублі тексту (його `repeats.py` лежить у цій же папці `pro/`).
- Контактний лист: `ffmpeg -i файл.mp4 -vf "fps=1/2,scale=180:-1,tile=8x3" sheet.jpg` і подивись (текст не на обличчі, немає спалахів спікера між перебивками).
- Покажи користувачу: тривалість, скільки перебивок, що вирізано (`notes`), попередження, що не перевірено (на слух, на реальному телефоні).

## Чого не робити

- Не ставь і не качай нічого без згоди користувача. Не проси токени й ключі в чат, не читай `.env`.
- Не редагуй скрипти рушія без запиту. Оригінали відео не змінюй і не видаляй: результат лише в `output/`.
- Не вигадуй текст плашок і назви файлів: назву дає замовник. Не став кадри з `sensitive`, якщо користувач цього не дозволив.
